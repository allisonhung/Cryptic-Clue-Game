# Cryptic Clue Game (Cryptic Kudos?)

## Overview
Do you enjoy writing or solving cryptic crossword clues? 
Here is a game where you can write clues, or solve and rate other users' clues. 
See how you stack with the various leaderboards and user stats. 

## How does it work?  
A new pinned post is created once "Install Game" is pressed by a mod. 
From this pinned post, you can check the leaderboards or you can submit a clue, which generates a new post. 
Each non-pinned post is a clue you can guess and rate. Each clue has an its own leaderboard for the fastest solvers as well. 

## User stats
We are always adding new stats, but right now we show your "win percentage", how many clues you've written, and the average rating for your clues. 

## Features
- Global leaderboard (for solvers and setters)
- Feedback and rating system for clues

## Technical Stack
- TypeScript
- Devvit Framework
- Reddit API Integration
- Custom Data Storage System
